# Voltus

> Voltus is a United States virtual power plant (VPP) operator and distributed energy resource (DER) aggregator, headquartered in San Francisco, that turns commercial, industrial, residential and transportation load and batteries into wholesale capacity across all nine North American organized markets (AESO, CAISO, ERCOT, IESO, ISO-NE, MISO, NYISO, PJM, SPP). Its API lets a channel partner, OEM or DER owner receive grid dispatches, report interval telemetry, and control enrolled sites. Documentation and a working sandbox are fully public; production access requires a commercial partnership and a signed Letter of Authorization per site.

Generated by API Evangelist from the Voltus developer portal and the harvested contract. No /llms.txt is published by Voltus (api.voltus.co/llms.txt returns 404, /docs/llms.txt returns 500) - this file is our faithful reconstruction.

Base URL: https://api.voltus.co/2022-04-15 (date-versioned; api.voltus.co redirects to the latest version)
Sandbox:  https://sandbox.voltus.co with header "X-Voltus-API-Key: secret" (public, no account needed)
Auth:     API key in the X-Voltus-API-Key header, issued by a Voltus account manager. No OAuth, no scopes.
Errors:   application/json {"message": "...", "type": "<HTTP status phrase>"} - not RFC 9457.
Limits:   x-ratelimit-limit / -remaining / -reset headers; observed 301 production, 101 sandbox.

## APIs

- [Voltus Dispatches API](https://api.voltus.co/docs/openapi/dispatches): List dispatches, retrieve one by id, create a test dispatch. Dispatches carry program, market, start/end time, modification_number and a per-site commitment.
- [Voltus Sites API](https://api.voltus.co/docs/openapi/sites): List the sites enrolled under your account and their meters (asset_type: load, battery, generator, poi).
- [Voltus Telemetry API](https://api.voltus.co/docs/openapi/telemetry): Submit interval telemetry and controllable load; read back up to 10 sites x 90 days x 10,000 points per request.
- [Voltus Webhooks API](https://api.voltus.co/docs/openapi/webhooks): Register HTTPS callbacks for dispatch.create and dispatch.update instead of polling.
- [Voltus OpenADR 2.0a VTN](https://api.voltus.co/docs/concepts/openadr): Standards-based alternative. Voltus runs the VTN, partners run VENs, polling Simple HTTP PULL over mutual TLS.

## Access

- Sandbox: anonymous, self-serve, no key needed - use "secret" against sandbox.voltus.co.
- Production: partner-only. No self-serve signup, no public pricing. Voltus obtains a signed Letter of Authorization and utility bill per site, then issues a site-scoped production key. Contact api-support@voltus.co.
